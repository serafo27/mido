# Keyboard shortcuts

| Shortcut        | Action                    |
| --------------- | ------------------------- |
| `⌘O`            | Open folder               |
| `⌘S`            | Save                      |
| `⌘1` `⌘2` `⌘3`  | Read · Split · Edit       |
| `⌥Z`            | Toggle line wrap          |
| `⌘P`            | Filter files              |
| `⌘\`            | Toggle sidebar            |
| `⌘B` `⌘I` `⌘K`  | Bold · Italic · Link      |
| `⌘F`            | Find in editor            |
